# ZIRVA Development

Адаптивный информационный сайт на React + Vite. Компоненты разделены по разделам страницы, данные вынесены в `src/data/company.js`, фирменные токены — в `src/styles.css`.

## Запуск

```bash
npm install
npm run dev
```

Сайт: http://localhost:5173. Production-сборка: `npm run build`; просмотр сборки: `npm run preview`. Каталог `dist` можно разместить на статическом хостинге.

## Источники

Контент и оформление взяты из «ББ Зирва (2).pdf», июнь 2026:

- страницы 3–5: история, позиционирование, миссия, видение и ценности;
- страницы 7, 11–13: оригинальный логотип, цвета, Benzin и Inter;
- страница 17: адрес, телефон и email группы компаний;
- страницы 19 и 31: иллюстрации и строительные краны.

Изображения из брендбука используются как иллюстрации направлений, а не как портфолио выполненных работ. Формулировки направлений и этапов — редакционное раскрытие позиционирования компании. Фактические объекты, статистика и клиентские отзывы не добавлялись, поскольку их нет в источнике. Телефон и email взяты с фирменного бланка, а не из визитки с демонстрационными контактами.

Шрифты: полноценный Inter из `@fontsource/inter`, локально поставляемый со сборкой. Основной текст — Regular 400, заголовки — Medium 500. Inter входит в фирменную типографику. Неполные наборы Benzin из PDF не используются: они содержали разные начертания и давали неодинаковую толщину букв. Скрипт `scripts/extract-brand.py` извлекает только графику (Python, pymupdf).

## Связь

Форма проверяет обязательные поля и открывает почтовый клиент с подготовленным письмом через `mailto:`. Она не отправляет данные на сервер и не показывает ложное подтверждение отправки. Для прямой отправки заявок нужен почтовый сервис или backend; папка `backend` оставлена без изменений. Телефон, email и ссылка на поиск адреса на карте работают независимо от формы.

## Проверка

```bash
npx playwright install chromium
# В другом терминале запустить npm run dev
node scripts/check-site.mjs
```

Проверка включает отображение шрифтов и изображений, мобильное меню, раскрытие направлений, подготовку письма, отсутствие горизонтального скролла на ширинах 320–1440 px и ошибок React. Скриншоты сохраняются в `artifacts/`.


## Публикация на GitHub Pages

Автоматическая публикация настроена в `.github/workflows/deploy.yml`.

1. Загрузить проект в GitHub-репозиторий, ветка `main` или `master`.
2. В репозитории открыть **Settings → Pages → Source → GitHub Actions**.
3. Запустить workflow **Deploy Zirva to GitHub Pages** во вкладке Actions (или отправить новый коммит).
4. Адрес опубликованного сайта появится в результате задания `deploy`.

Путь репозитория определяется автоматически через `actions/configure-pages`. Изображения, шрифты и якорные ссылки поддерживают публикацию в подкаталоге. Вручную менять название репозитория в коде не нужно.

Проверка сборки в подкаталоге:

```bash
npm run build -- --base=/zirva/
npm run preview -- --base=/zirva/
```

Открыть http://localhost:4173/zirva/. Форма связи сохраняет текущий режим `mailto:`.

Настройка основана на [руководстве Vite для GitHub Pages](https://vite.dev/guide/static-deploy.html#github-pages).
